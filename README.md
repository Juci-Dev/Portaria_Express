
# 🏠 Portaria Express - Sistema de controle de Encomendas de Moradores

Este é um projeto desenvolvido com **Python / Flask** e **MySQL**. O projeto consiste no desenvolvimento de um sistema web para registro e controle de encomendas em portarias prediais, com o objetivo de otimizar a gestão de entregas destinadas aos moradores.

O sistema permitirá o cadastro, controle e acompanhamento da retirada de encomendas, garantindo mais organização, segurança e agilidade no processo com o CRUD completo (Create, Read, Update, Delete).

---

## 🚀 Funcionalidades
- Funcionalidades
📦 Cadastro de encomendas
🧾 Registro de moradores
🔍 Consulta de encomendas registradas
📊 Controle de status/ Notificação (entregue / pendente / Notificado)
🗂️ Organização e controle da portaria

---
